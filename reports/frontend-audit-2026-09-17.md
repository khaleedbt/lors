Исходники: `/Users/coder/Documents/Projects/js/lors`. Изменений в репозитории фронтенда не сделано. Проверены React/TypeScript, API-клиент, формы, выбор автомобиля, трекинг, сборка, зависимости и deploy-конфигурация. Реальные заявки не отправлялись. Сборка выполнялась в отдельной временной копии.

## Найденные ошибки

1. **Высокий приоритет: падение страницы при товаре без цвета.** `src/components/Products.tsx:30` обращается к `v.color.name`. В Django поле ProductVariant.color допускает null, в TypeScript ошибочно объявлено обязательным Color (`src/api/types.ts`). Реальное выполнение компонента через React SSR с допустимым ответом API воспроизводит `Cannot read properties of null (reading 'name')`. В приложении нет ErrorBoundary, поэтому ошибка может убрать весь интерфейс. Исправить тип на Color | null и безопасно формировать подпись варианта.

2. **Средний приоритет: ответы старого запроса перезаписывают выбор марки.** `src/hooks/useCarPicker.ts:18–27` и `src/hooks/useMatCarPicker.ts:43–54` не отменяют запрос и не проверяют актуальность ответа. При быстром переключении A → B более медленный ответ A перезапишет список после ответа B; возможен выбор автомобиля другой марки. При начале загрузки старый список также не очищается. Добавить AbortSignal или cleanup с проверкой актуальности и очищать прежние модели. Это вывод из кода, браузерное воспроизведение не выполнялось.

3. **Средний приоритет: неверная стоимость при отказе справочников.** `src/components/MatCalculator.tsx:53` загружает пять справочников через Promise.all и игнорирует общий отказ. Достаточно ошибки любого запроса, чтобы pricingSettings оставался null; строка 107 заменяет цену багажника нулём. UI и WhatsApp могут показывать заниженную стоимость, хотя backend считает по реальной цене. Загружать независимо, показывать ошибку загрузки цены и запрещать расчёт с неизвестной ценой выбранной опции.

4. **Средний приоритет: пагинация теряет настроенный адрес API.** `src/api/client.ts:44` сохраняет только pathname/query следующей страницы. С VITE_API_BASE_URL=https://api.example/api первый запрос идёт к API, второй — на origin фронтенда. Воспроизведено с mock fetch: `["https://api.example/api/brands/", "/api/brands/?page=2"]`. При текущем размещении под /api ошибка не проявляется. Следующие страницы нужно строить относительно настроенного API с проверкой допустимого origin/path.

5. **Средний приоритет: вымышленный контакт WhatsApp при отказе настроек.** `src/App.tsx:17–36` подставляет `963900000000`, пока настройки не получены или загрузка закончилась ошибкой. Клиент может отправить заказ и свои имя/телефон на неподтверждённый номер. Это подтверждённая подстановка; существование и владелец номера не проверялись. Скрывать или отключать связь до появления валидного контакта; резервный контакт должен быть подтверждённым.

6. **Низкий приоритет: выбор файлов не соответствует ограничениям сервера.** `src/components/MatCalculator.tsx:544` принимает произвольное число файлов без проверки размера и суммарного объёма. Backend допускает до 10 файлов по 8 МБ, nginx — только 20 МБ на весь запрос. Пользователь может выбрать файлы, каждый из которых допустим, но отправка завершится 413; интерфейс покажет только общую ошибку. Проверять число файлов, размеры и общий объём с запасом на multipart; отображать ошибки uploaded_photos и 413. Это проблема интерфейса; серверные лимиты уже существуют.

## Риск повторного развёртывания небезопасной конфигурации

`deploy/lorssy.com.nginx.conf:10` в репозитории фронтенда всё ещё раздаёт /media/ без исключения для приватных /media/leads/. Строка 38 также использует $proxy_add_x_forwarded_for. Если применить этот файл поверх исправленного nginx, фото заявок снова станут доступны по URL без авторизации. После установленных в Django NUM_PROXIES=1 сам по себе старый proxy_add_x_forwarded_for уже не воспроизводит прежний обход через первый элемент, но расходится с согласованной схемой перезаписи заголовка. Синхронизировать шаблон с актуальным `deploy/nginx_lorssy.com.conf` backend-репозитория. Рабочий сервер по предыдущим проверкам уже использует исправленную конфигурацию; текущая публичная утечка этим аудитом не установлена.
